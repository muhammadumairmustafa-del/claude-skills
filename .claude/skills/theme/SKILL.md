# Theme: Wada colour combinations

Sanzo Wada's 1933 *Dictionary of Color Combinations* is a hand-curated set of colour pairings that designers still use, because each one has been balanced by eye rather than generated by a formula. This skill lets you use those exact combinations instead of guessing at hex values, and handles the part the book doesn't: turning a 2–4 colour combination into a usable UI theme with legible text.

Everything lives next to this file:

- `scripts/theme.py` does the work (search, role assignment, contrast checks, export). Use it instead of reading the data by hand, which keeps the context small and the maths correct.
- `data/wada.json` holds `colors` as `[name, hex, [c,m,y,k], [r,g,b]]` and `combos` as 348 lists of colour indexes; combination N is `combos[N-1]`.
- `assets/gallery.html` is a self-contained browsable gallery of all combinations (click to copy hex, filter by colour). Copy it to the user's project or open it when they want to browse and choose for themselves.

Run the script with `python3 ~/.claude/skills/theme/scripts/theme.py <command>`.

## Workflow

### 1. Work out what the theme is for

Read the brief (and the project, if there is one) for: subject and mood, light or dark UI, any colour that must stay (an existing brand colour or logo), and the output format the project uses (plain CSS, Tailwind, SCSS, a pptx/design tool that needs hex). Don't interrogate the user. Infer what you can and state your assumptions.

### 2. Shortlist combinations

```bash
theme.py find --mood warm --mood earthy --size 3        # mood words combine
theme.py find --near "#0a66c2" --size 4                  # keep a brand colour
theme.py find --has "Prussian Blue"                      # must include a named colour
theme.py show 117 250 301                                # a specific number the user named
theme.py color "sea green"                               # every combo using a colour
```

Moods: `warm cool muted vivid pastel light dark earthy contrast soft`. The ranking is a starting point, not a verdict. Read the hexes and pick with taste for the subject (a children's product, a law firm and a jazz bar want very different things). Use `--size 3` or `4` when the design needs separate background, text and accent roles; a pair works for posters, covers and two-tone marks.

Offer the user 2–3 candidates with a one-line reason each, unless they asked you to just decide, in which case pick one and say which and why.

### 3. Turn the choice into tokens

```bash
theme.py tokens 250                      # CSS custom properties, light
theme.py tokens 250 --dark               # dark theme from the same combination
theme.py tokens 250 --format tailwind    # also: scss, json
theme.py tokens 250 --prefix wada-       # namespacing, e.g. --wada-accent
```

The script assigns `background`, `text`, `surface`, `accent`, `accent-2…` and `on-accent`, and prints the contrast ratios in a header comment. How it decides:

- The original Wada colours are kept exactly. When the combination has no colour light enough (or dark enough) to be a page background, it derives a tint or shade of the closest one, and labels it as such in the comment.
- Text always reaches at least 4.5:1 on the background (WCAG AA). When no colour in the combination gets there, it darkens or lightens the strongest one rather than falling back to generic black.
- The header warns when an accent is below 3:1 on the background. Use such accents for fills, illustration and large areas, not for small text, thin lines or icons.
- `on-accent` is the most legible colour for text on accent-filled buttons. A few mid-tone accents only reach about 4.3:1, which is fine for button-sized bold text but not for small print.

For a theme with both modes, generate both and put the dark set under `@media (prefers-color-scheme: dark)` and/or a `[data-theme="dark"]` selector, matching how the project already toggles themes.

### 4. Apply it

Wire the tokens into the project's existing system (CSS variables file, Tailwind config, theme object) rather than sprinkling hex values through components. Then look at the result (screenshot or browser preview) if you can. Combinations that look balanced as swatches can feel different at real proportions, so adjust which colour takes the large areas if needed.

Proportion matters more than the list. A common approach is to let the background colour cover most of the area, use the second colour for structure (text, headings, panels), and keep the most saturated colour for small, deliberate moments (buttons, highlights, one illustration).

### 5. Credit the source

When reporting back, name the combination (`Wada No. 250: Pyrite Yellow, Peach Red, Sea Green, Nile Blue`) so the user can find it again in the book or the gallery, and mention any derived tints or shades.

## Notes on the data

- The book prints CMYK only. The HEX and RGB values are screen conversions, so printed swatches will look slightly different. For print work, hand over the CMYK values from `theme.py show`.
- Four CMYK values (Citrine, Rainette Green, Diamine Green, Dull Violet Black) were corrected against the book scan. Their HEX is still the original conversion, so treat it as an approximation.
- Combinations 1–120 are pairs, 121–240 are trios, and 241–348 are quartets, matching the book's numbering.
