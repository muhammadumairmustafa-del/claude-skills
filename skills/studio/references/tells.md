# Generated-design tells

Things that make a UI read as "an AI made this". They aren't forbidden — the brief's own words always win, and a chosen direction may deliberately use one — but they must never appear *by default*. If one shows up and nobody chose it, remove it.

Don't fix a tell by swapping in the "approved alternative" every time: replacement lists become the next generation of tells. Fix it by going back to the subject and asking what *this* product would do.

## Look clusters (whole-page defaults)

1. **Cream + serif + terracotta** — #F4F1EA-ish background, high-contrast serif display, clay accent near #D97757. The "tasteful editorial" fix has itself become a tell.
2. **Near-black + one acid accent** — #0B0B0B background with a single acid-green / vermilion / electric-blue highlight.
3. **Broadsheet** — hairline rules everywhere, 0 radius, dense newspaper columns, when the content isn't news.
4. **SaaS card kit** — everything chopped into identical rounded cards, one radius on everything, the same rgba(0,0,0,.1) shadow, gradient washes as decoration, purple-to-blue gradients.
5. **Stock page skeleton** — hero → logo strip → 3 feature cards with icons → testimonial → pricing → CTA, regardless of what the product needs to say.

## Chrome (small defaults that add up)

- Tracked-out ALL-CAPS eyebrow label above every heading.
- Accenting one word in a headline (italic, gradient, or different colour).
- Gradient text.
- Meta strings joined with middle dots ("A · B · C") and labels like "WORD — fragment".
- "→" appended to every link and button.
- Monospace as a "technical" costume for small labels when the product isn't technical.
- Numbered markers (01 / 02 / 03) on content that isn't a sequence.
- Big number + small label + gradient accent stat rows as the default hero.
- Emoji used as icons; mixed icon sets.
- Coloured left-border (>1px) on cards/callouts as decoration.
- Nested cards (card inside card inside card).
- Fade-and-slide-up on every section; hover lift on every card.
- Glow/blur blobs in the background with no reason.
- "Unlock", "Elevate", "Seamless", "Supercharge", "Revolutionise" copy; three-adjective taglines.
- Placeholder-feeling content: "John Doe", "Lorem", "Acme", round fake numbers like 10,000+ users.

## Process tells

- Every project lands on the same 3 fonts (Inter, Space Grotesk, Playfair). Check `direction.py history` — if a choice repeats across projects, it's a habit, not a decision.
- Removing ornament and leaving nothing: "minimal" that reads as thin. Replace decoration with substance — larger type, real imagery, whole fields of colour, actual content.
- Boldness spread everywhere. Spend it in one place (the signature moment); keep the rest quiet.
